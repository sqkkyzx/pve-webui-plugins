# 模块与站点管理

## 统一表格

左上角选择「--插件--」，根页面显示「模块与站点」。表格包含顺序、类型、名称、开发进度、启用状态、显示别名、图标和站点目标。

「类型」以蓝色标识「功能模块」、橙色标识「附加站点」，同时保留文字。左侧树以「模块 /」和「站点 /」区分条目，新增站点直接加入树。点击模块后，中间显示带图标的原生竖向菜单，可切换介绍、基本配置和帮助文档，右侧显示对应内容；点击站点定位管理表格中的对应行；表格中的「模块配置」直接进入基本配置页。

「开发进度」同时显示功能覆盖范围与成熟度，悬停可查看边界说明。两项由项目随版本维护，启停模块不会改变进度。当前 Komodo 与 SafeLine WAF 为「部分管理 · 测试中」，节点温度为「只读监测 · 测试中」。站点显示「外部站点」，宿主不评定目标应用的开发阶段。详细范围见 [[内置模块|Modules]]。

模块停用后仍可查看介绍与帮助文档。SafeLine 的基本配置在启用模块并保存后开放；停用时不请求其连接 API。

## 编辑和保存

选中表格行后点击「编辑」或双击该行。模块可编辑启用状态、别名和图标，站点还可编辑名称及目标 URL。窗口中的「保存」立即应用该条目。

上移、下移修改表格中的混合顺序，顶部「保存并应用」将其保存到服务器。左侧树和视图菜单使用同一份顺序，PVE 原生视图与「--插件--」入口位于菜单顶部。节点温度集成到节点概要，菜单呈现与其功能位置对应。

Komodo 连接与温度来源按顶部「保存并应用」。温度来源窗口的「确定」只更新草稿，仍需保存；SafeLine 使用基本配置页自己的保存和测试按钮，测试连接后仍需点击「保存连接」。模块启停或 Komodo、温度来源变更会刷新页面，并关闭插件终端连接。有未保存的连接或排序草稿时，先保存草稿再切换模块状态。

配置发生修订冲突时，重新读取最新内容后再编辑。

## 别名与图标

默认模块名称为 `Komodo`、`节点温度` 和 `SafeLine WAF`。别名留空时使用默认名称，Komodo 可以由用户自行改为「容器视图」。站点名称与显示别名分别保存，原始名称在站点信息中可查看。

图标来源支持默认或自动、PVE 原生图标类名、HTTP(S) 图标 URL。原生类名例如 `fa fa-server`、`fl fl-docker`。图标 URL 使用完整地址，编辑窗口提供预览。

站点自动图标按已保存地址探测页面声明的图标，回退到 `/favicon.ico`，获取失败时使用通用图标。手动图标设置生效后，站点使用对应设置。

## 附加站点

附加站点是内置能力，每个站点独立启停。停用站点保留其数据，同时从视图菜单移除并停止已打开的嵌入页面。

管理表格中的「打开站点」进入嵌入页面。左侧「站点信息」使用单列表格，每个字段名独占灰底行，对应值位于下一白底行。完整地址按列宽换行，工具栏提供刷新与新标签页打开。

嵌入结果由目标站点的 CSP、X-Frame-Options、登录流程以及浏览器混合内容策略共同决定。目标禁止嵌入时，可使用「新标签页打开」访问站点。

站点记录由宿主上的获准管理员共享，各目标站点继续使用自己的登录机制。

## 设置存放位置

| 内容 | 默认路径 |
| --- | --- |
| 模块选择、Komodo 凭据、温度来源、模块别名和图标、混合顺序 | `/app/data/plugins.json` |
| 站点名称、URL、启用状态、别名、图标和修订 | `/app/data/sites.sqlite3` |
| Komodo 操作与 VM/CT 关联 | `/app/data/actions.sqlite3`、`/app/data/guest-links.sqlite3` |
| SafeLine 连接与 Token | `/app/data/safeline.sqlite3` |
| 自动生成的网关证书与私钥 | `/app/data/proxy/cert.pem`、`/app/data/proxy/key.pem` |

这些文件包含私有配置或凭据，备份按相同权限保护。直接运行 Python 时，统一数据目录由 `PVE_PLUGINS_DATA_DIR` 指定，默认当前工作目录下的 `data`。Compose 默认使用命名卷 `pve_webui_plugins_data` 挂载 `/app/data`。宿主配置只接受 schema 2，导航包含 `entry_order`、`module_aliases`、`module_icons` 三个字段。基础节点 IP 列表、白名单、网关开关和 TLS 环境配置在重建容器时应用。
