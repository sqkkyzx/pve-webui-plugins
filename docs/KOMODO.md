# Komodo / Docker 插件功能

本扩展把 Komodo 的 Docker 管理功能接入 PVE 9 桌面，使用 PVE 原生的 ExtJS 菜单、树、表格和编辑窗口。浏览器通过同源接口访问扩展，Komodo API 凭据保留在服务端。

扩展不修改 PVE 官方文件、VM/CT 配置或 PVE API。它需要现有 Nginx 配合：桌面入口和扩展接口经过 FastAPI，其余 PVE 请求仍直接代理到 PVE。保留原始 PVE 管理入口，可随时绕过或停用扩展。

## 第一版功能范围

| 入口 | 已实现的功能 |
| --- | --- |
| 数据中心 → Docker | 服务器、应用栈、流程表格；搜索、标签与模板筛选；资源计数、使用率；平铺的批次操作按钮与确认窗口 |
| Docker → 容器 | 跨服务器容器列表、筛选、多选，以及启动、重启、暂停、恢复、停止、销毁 |
| Docker → 告警 | 类型、资源与未解决状态筛选，分页和只读详情 |
| Docker → 操作 | 资源与操作筛选，分页，单条操作的结果、时间和阶段详情 |
| 容器视图 | 服务器 → 应用栈 → 容器三级树；独立容器放在服务器的“容器”分组；直接打开应用栈或容器专属页 |
| 附加站点 | 左侧新建、选择和编辑站点，右侧 iframe 展示，顶栏支持刷新、编辑和确认移除 |
| 服务器 Docker 页 | 概要、选项、DOCKER、资源、终端；已关联服务器出现在对应 VM/CT 下，未关联服务器使用独立管理页 |
| 应用栈专属页 | 配置、信息、日志、终端，以及部署、拉取镜像、重启、暂停、停止、销毁 |
| 容器专属页 | 概览、日志、检查、终端，以及随当前状态调整的重启、暂停/恢复、停止/启动和销毁 |
| 新建服务器 | 唯一名称，可选关联一个 VM/CT，也可不关联；保留创建成功但关联未完成的回执 |
| PVE 节点概要 | 自动取得 PVE 节点 IP，读取 node_exporter 温度及感测器明细；沿用 PVE 会话，不需要 Komodo 凭据。见[温度接入说明](../TEMPERATURES.md) |

以下功能在第一版中保留占位，不代表已经实现：

- 数据中心 Docker 下的“统计”和“计划任务”页面为空白页。
- 数据中心首页的“新建应用栈”和“新建流程”按钮禁用；服务器“资源”页已支持在该服务器上新建应用栈。
- 服务器“资源”页读取部署和代码仓库列表，但它们的新建、执行及专属页跳转尚未开放。

界面按当前数据和服务账号权限启用按钮。未获取到的指标显示 `-`，真实零值保留为 `0`；服务器离线或监控缓存缺失时，空列表不作为“没有容器”的证明。

### 附加站点

左上角视图选择器提供“附加站点”。新建时填写名称和完整 HTTP(S) URL，选中后在右侧显示。右侧顶栏的“刷新”重新载入已保存的站点 URL；“编辑”可修改名称、URL；“移除”确认后仅删除保存的链接，编辑表单内也保留删除入口。站点由获准使用扩展的 PVE 管理员共用，保存在服务端，刷新或换浏览器后仍可读取，不需要 Komodo 凭据。

页面直接加载管理员添加的可信站点，不经过后端内容代理。目标站点的 `X-Frame-Options`、CSP 或第三方 Cookie 限制可能阻止嵌入、登录；HTTPS PVE 页面也不能嵌入普通 HTTP 页面。站点自身需要允许相应的 iframe 使用方式，扩展不会绕过这些限制。离开站点视图或登出时清理 iframe。

### 容器视图与服务器页面

左上角视图选择器保留 PVE 原有视图，并增加“容器视图”。已确认关联的服务器使用 PVE 的 VM/CT 图标与状态标记，名称格式为：

```text
ID VM/CT名称 [Komodo服务器名称]
├── 应用栈
│   └── 容器
└── 容器
    └── 独立容器
```

应用栈归属使用 Komodo 服务清单核对服务器 ID 和完整 Docker 容器 ID，不按名称、前缀或 Compose 项目名猜测。归属未知或冲突的容器保留在独立分组并提示。树的展开和选中状态与 PVE 官方资源树分开保存，不把 Docker 容器注册成 PVE CT。

容器图标沿用 PVE 原生状态样式：运行时显示绿色播放角标，暂停时显示黄色暂停角标，停止或尚未启动时变灰。详细状态显示在悬停提示中；未知和异常状态分别使用问号和错误角标。

服务器 Docker 页包含：

- **概要**：当前状态与 CPU、内存、磁盘、网络等可用指标，可编辑的服务器描述，最近操作，容器、磁盘、进程表格，以及六张历史图。历史读取固定采样间隔，网络历史显示每次采样的字节量。
- **选项**：以“常规 / 告警”深灰标题和小项浅灰标题分组，显示描述；通过选中后编辑或双击编辑单个字段。包括启用、认证、公钥、地址、磁盘过滤、监控、清理、告警阈值和维护窗口。公钥保存与密钥轮换是独立操作；不显示私钥。
- **DOCKER**：容器、网络、存储卷、镜像按两行两列排列。表格支持本地搜索、多选及对应操作；系统内置网络不可选。容器行的跳转按钮打开该完整容器 ID 的专属页。
- **资源**：应用栈、部署、代码仓库纵向排列。应用栈支持新建、检查更新、拉取、部署、重启、停止、销毁、删除及专属页跳转；部署和仓库的管理按钮保留占位。
- **终端**：选择默认命令、`sh`、`bash` 或自定义命令，连接该服务器的 Periphery 终端。

概要页“刷新”旁提供“关联 VM/CT”“解除关联”“打开 PVE 对象”，与数据中心首页共用关联窗口。关联变更后刷新树，并按重新读取的关联重建 VM/CT Docker 页或独立服务器页，避免继续使用旧目标或旧版本。

### 应用栈与容器

应用栈配置按“常规 / 高级”和小项标题分组，只展示界面已支持的字段。环境变量、文件列表、部署前后命令、命令包装器及服务选择使用对应编辑器；保存仅提交修改的字段，并检查资源版本。

“信息”页可读取和编辑允许写入的 Compose/配置文件，显示上次部署配置。保存 Git 来源文件可能提交并推送代码仓库；修改配置来源或文件也可能按 Komodo 的自动更新策略触发部署，确认窗口会说明效果。命中集成凭据而经过脱敏的字段或文件禁止回写。

容器概览第一行展示当前状态、共享服务器描述与服务器操作记录，第二行展示容器信息和 Docker 配置。这里的描述与操作记录属于服务器，由同机容器共用；编辑描述只更新服务器元数据。检查页按权限显示可上下、左右滚动的 Docker inspect JSON。

应用栈与容器日志支持行数、搜索、反向匹配、时间戳、stdout/stderr 和可选的 10 秒轮询；离页停止轮询。应用栈可筛选服务。搜索使用 Komodo 日志搜索接口，范围为最近 5000 行；搜索合并输出时界面会说明。

容器终端提供 `sh`、`bash`、`attach` 和自定义命令。`attach` 连接容器主进程，输入会作用于该进程。应用栈终端从运行中的服务选择容器及 `sh`/`bash`。

所有终端共用 PVE 自带的 xterm.js、同源 WebSocket、自适应尺寸、滚动和全屏实现。每次授权都重新检查目标与 Terminal 权限；离页关闭并清理本次独立 PTY，不接管其他会话，也不自动重连。会话最长 30 分钟，空闲 10 分钟结束，活动期间定期复核权限及目标。Core 不可达时远端清理可能失败，需在 Komodo 核对遗留终端；扩展仍会关闭转发。


## 身份、权限与写操作

每个集成 API 请求先核验浏览器现有的 `PVEAuthCookie`，检查完整用户 ID 白名单，并向固定 PVE 上游验证登录、完整双因素认证状态及 `/` 上的 `Sys.Audit`。验证使用原票据，不替用户创建或续签票据。

PVE Cookie 只发给 PVE；Komodo key/secret 只发给固定 Core。浏览器不能提供任意 RPC、上游地址或 Mongo 查询。Komodo 资源是否可读、可执行、可写，仍由服务账号在 Core 的当前权限决定；PVE VM 权限不会自动转成 Komodo 操作权限。新建服务器还检查原生创建权限与 Core UI 禁写设置。

写请求要求集成自己的 `X-PVE-Plugins-CSRF` token，并校验请求来源；PVE 原生 CSRF header 不能替代它。token 与 PVE 票据绑定，服务重启、票据变化或过期后需刷新取得新 token。终端的授权和 WebSocket 打开也执行会话、来源与 token 校验。

- 资源操作先确认全部目标，再按固定 ID 派发；最多选择 50 个目标，写前复核权限、状态及适用的版本或关联修订号。
- 操作、配置保存和新建使用 UUID 与持久化回执防止重复执行；终端使用一次性授权，并在建立会话前登记 UUID 账本。关联元数据使用 SQLite 事务及修订号防止覆盖旧状态。
- 已发出的 POST 不因切页而重发或被当作撤销；异步操作“已提交”不等于已完成。
- 超时或结果不明确时不自动重试。先在 Komodo 操作记录和资源列表核对结果，再决定后续操作。
- 容器销毁会删除可写层；存储卷删除和系统清理可能删除数据；应用栈删除会先移除实际部署。每个确认窗口说明实际影响。

列表和操作详情只返回界面所需字段，上游错误原文不会直接显示。配置文件和 inspect 页按权限展示应用配置，不能当作通用秘密清除器；集成自身已知凭据会脱敏。动作账本不保存原始编辑内容，只保存请求指纹及必要回执。

### API 路径速查

以下接口都位于增强入口的同源路径；除健康检查外，访问前均核验 PVE 会话。这里列出固定接口族，不接受浏览器指定任意 Core RPC。

| 路径 | 方法与用途 |
| --- | --- |
| `/pve-plugins/health` | `GET`，服务存活检查 |
| `/pve-plugins/api/session`、`/pve-plugins/api/komodo/connection` | `GET`，集成会话与 Core 连接检查 |
| `/pve-plugins/api/komodo/dashboard`、`/pve-plugins/api/komodo/containers` | `GET`，首页与跨服务器容器列表 |
| `/pve-plugins/api/komodo/alerts`、`/pve-plugins/api/komodo/updates`、`/pve-plugins/api/komodo/updates/{id}` | `GET`，固定筛选的告警、操作和操作详情 |
| `/pve-plugins/api/komodo/action` | `POST`，数据中心固定批次动作 |
| `/pve-plugins/api/komodo/guest-links` | `GET` 关联及候选列表，`POST` 确认关联 |
| `/pve-plugins/api/komodo/guest-links/unlink` | `POST`，按修订号解除映射 |
| `/pve-plugins/api/komodo/server-create-options`、`/pve-plugins/api/komodo/servers/create` | 分别为 `GET` 创建权限与候选，`POST` 新建服务器 |
| 服务器基础路径 + `/summary`、`/history`、`/options`、`/docker`、`/resources` | `GET`，服务器各页数据 |
| 服务器基础路径 + `/options`、`/description`、`/actions`、`/inventory-actions` | `POST`，配置、描述与固定动作 |
| `/pve-plugins/api/komodo/stacks/{stack_id}` | `GET` 应用栈详情，`POST` 部分配置或文件保存；另有 `GET /logs` 和 `POST /actions` |
| `/pve-plugins/api/komodo/servers/{server_id}/containers/{container_id}` | `GET` 容器详情，`POST` 共享服务器描述；另有 `GET /logs`、`GET /inspect` 和 `POST /actions` |
| 服务器、应用栈或容器基础路径 + `/terminal-services`、`/terminals`、`/terminals/ws` | 分别为 `GET` 终端选项、`POST` 一次性授权和 `WS` 交互会话 |

服务器基础路径在已关联时为 `/pve-plugins/api/komodo/guests/{qemu或lxc}/{vmid}`，未关联时为 `/pve-plugins/api/komodo/servers/{server_id}`。接口查询字段、JSON 字段和数量均有固定校验；资源版本或关联修订不匹配时返回冲突，不能以改传另一个 ID 绕过。

### VM/CT 关联与独立服务器

关联只写本扩展的本地数据库，不修改 VM/CT、Komodo 服务器配置或 Docker 服务。同名仅作为候选推荐，需要明确选择和确认；一台 VM/CT 只能关联一个 Komodo Server，不能覆盖另一台服务器占用的客体。

关联核验使用 VM 的 SMBIOS UUID，或 CT 的网卡 MAC 集合。VM 身份通常更强；CT 为弱校验，克隆或使用相同 VMID/MAC 重建无法被绝对区分。客体迁移或改名会重新读取节点与名称；身份变化、客体不可见或查询失败会保留映射并禁止未经核验的跳转，不自动改绑。

新建服务器可不关联。选择关联时，扩展在创建前后核对身份；若 Core 已创建成功而本地关联失败，回执保留服务器 ID 并显示“关联未完成”，不会通过删除或再次创建来补偿。

未关联服务器使用 `/servers/{server_id}/...` 独立页，固定 `binding_revision: 0`。该模式在读取、写前及终端活动期间复核服务器仍无活动关联；已有活动关联必须从对应 VM/CT 路径进入，继续检查客体身份。`/guests/{guest_type}/{vmid}/...` 不接受伪造的直接服务器上下文。容器专属页仍以服务器 ID 与完整 64 位容器 ID 唯一定位，不依赖名称。

正常解绑仅释放映射。已删除或不可访问服务器留下的孤立映射，可在关联窗口明确执行“解除失效关联”；清理不会自动关联当前服务器或跳转到另一台服务器。


部署與插件選擇見[主文件](../README.md)。Komodo 插件停用時，對應業務 API 不會註冊。
